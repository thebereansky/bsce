# The Berean Sky Prompt Library

## Purpose

The Prompt Library contains reusable AI instructions used by the Berean Sky Content Engine.

Prompts are version controlled and treated as project assets.

---

# Prompt Naming Convention

Format:

[Content Type]-v[Version]

Example:

master-study-v1.0.md

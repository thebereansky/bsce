# Project Overview

The Berean Sky Content Engine (BSCE) is an AI-powered Christian publishing platform designed to transform a single Study definition into a complete ecosystem of educational, publishing, marketing, and media assets.

Primary Goal:

Create biblically faithful, creation-focused content that can be published across multiple channels with minimal manual effort.

Tagline:

Searching the Scriptures.
Exploring Creation.

---

# Core Architectural Principles

## Single Source of Truth

Each Study is the canonical content object.

All downstream assets are generated from the Study.

Study
↓
Master Study
↓
Family Guide
↓
Lesson Series
↓
Lesson Scripts
↓
Shorts
↓
Video Assets
↓
Publishing Assets
↓
Product Assets

---

## Automation First

BSCE is designed to automate:

- Prompt generation
- Asset generation
- Product generation
- Marketing generation
- Packaging
- Publishing preparation

Human approval remains required before publication.

---

## GitHub First

GitHub serves as the canonical repository for:

- Studies
- Prompt templates
- Configurations
- Registries
- Documentation

Google Drive serves as the operational content repository.
